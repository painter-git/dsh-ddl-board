# DDL 看板 / DDL board

左侧栏里的截止任务看板。点左侧栏的「DDL 看板」图标打开面板。

## 安装

要求 DeepSeek Harness `0.2.2-rc.3` 或更新。在 DSH 里：左侧栏 **Plugins** → 右上 **Add plugin**（添加插件），然后填其中一种：

| 方式 | 填什么 | 说明 |
| --- | --- | --- |
| Git 仓库（推荐） | `https://github.com/painter-git/dsh-ddl-board` | 安装会固定到当时的 commit；升级时移除后重新安装 |
| 本地文件夹 | `D:\plugins\ddl-board`（绝对路径） | 解压 zip 后填该文件夹；文件夹不能删或移动 |
| 压缩包 | `D:\plugins\ddl-board-1.0.0.tgz`（绝对路径） | 单文件；该文件要保留 |
| npm 包 | 发布后的包名 | 需要先发布，可一键升级 |

装完刷新页面，左侧栏 Schedules 之后会出现 **DDL 看板**。卸载：Plugins → 打开该 bundle 页面 → 移除。

## 功能

- **新建 DDL**：填写事件名称、截止时间（必填）、预计完成时间（可选）和备注。
- **时间输入**：直接打字，年份只写两位，例如 `26-11-20 18:00`。
  - 也接受 `2026-11-20 18:00`、`26/11/20`、`26.11.20`、`26年11月20日 18:00`、全角数字。
  - 只写日期（`26-11-20`）默认当天 `12:00`；只写月日（`11-20`）默认今年，若那一天已经过去则算明年。
  - 输入框下方会显示补全后的完整时间（`→ 2026-11-20 18:00`），提交前就能确认年份。
  - 右侧的日历按钮仍可打开系统日期选择器。
- **小任务**：每个大任务下可添加一级小任务（不能继续嵌套），每个小任务有自己的预计完成时间。
- **完成状态**：大任务和小任务都可以勾选完成；已完成的大任务收在页面底部的「已完成」分组里。
- **排序**：
  - 大任务先按**预计完成时间**排序；某个大任务没有填预计完成时间时，它按**截止时间**参与排序。
  - 每个大任务下的小任务按各自的**预计完成时间**排序；没填预计完成时间的小任务不参与排序，保持添加顺序并排在已填的小任务之后。
- 逾期的大任务会显示「已逾期」并高亮边框；预计完成时间晚于截止时间时显示「预计晚于截止」提示。

## 数据保存

主机把看板保存成一个 JSON 文件：

- 默认 `$DSH_HOME/ddl-board/state.json`（`DSH_HOME` 未设置时为 `~/.dsh`）。
- 可用环境变量 `DSH_DDL_BOARD_FILE` 指定其他路径。

页面通过同源路由 `/plugin/ddl-board/state` 读写该文件。存储出问题时页面顶部会出现一条提示，而不是静默改写数据：

- **主机看板文件读不到**：改用这台浏览器里的副本，提示条上有「重试」。
- **保存失败**：改动先留在浏览器里并标记为未写入主机，提示条上有「重试」。
- **浏览器里有未写入主机的副本**（例如保存失败后重新打开页面）：提示条会说明有这份副本，可选择「恢复这份副本」把浏览器副本写回主机，或「忽略」保留主机上的版本。

主机只读取自己写出的文档：文件损坏时路由返回错误、保持文件原样，页面因此不会用空看板覆盖它。

## 限制

- 数据只存在本机，没有跨设备同步。
- 没有提醒/通知功能；排序与逾期提示按打开页面时的本机时间计算。
- 小任务只有一级。
- 没有搜索或筛选：任务多时靠页首排序规则与小任务折行来浏览。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.js` | 主机部分：`/plugin/ddl-board/state` 路由，读写上面的 JSON 文件 |
| `client.js` | 浏览器部分：`sidebar.panellist` 侧栏入口与 `main` 面板页面 |
| `cordis.patch.yml` | 插入 `ddl-board` 插件行的 bundle patch |
| `locale/*.json` | 插件管理器中显示的名称与说明 |
